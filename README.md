# tick_tack_toe_rust

A two-player tic-tac-toe game in the terminal, written in Rust.

## How it works
- 3x3 board, players X and O take turns entering a row and column.
- Invalid moves are rejected and the player is asked again.
- The game checks rows, columns, and diagonals for a win, and reports a draw when the board is full.

## How to run
```bash
cargo run
```
